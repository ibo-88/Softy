## 📋 Рекомендации по использованию:

### 1. **Перед запуском:**
```bash
# Установите зависимости
pip install -r requirements.txt

# Создайте папки
mkdir -p sessions uploads

# Запустите платформу
python app.py
```

### 2. **Настройка аккаунтов:**
- Поместите .session файлы в папку `sessions/`
- API ключи извлекаются автоматически
- Настройте прокси для каждого аккаунта

### 3. **Использование парсинга:**
- Выберите активный аккаунт
- Укажите ссылку на канал/чат
- Установите лимит участников
- Запустите парсинг

### 4. **Массовая рассылка:**
- Загрузите файл с юзернеймами
- Настройте сообщение
- Установите задержки
- Запустите рассылку

## ⚠️ Важные замечания:

### 1. **Соблюдение лимитов Telegram:**
- Не более 50 сообщений в день для новых аккаунтов
- Используйте реалистичные задержки (3-10 сек)
- Ротируйте аккаунты каждые 10-20 сообщений

### 2. **Безопасность:**
- Используйте качественные резидентские прокси
- Мониторьте статистику ошибок
- Регулярно обновляйте аккаунты

### 3. **Производительность:**
- Не запускайте более 20 потоков одновременно
- Мониторьте использование памяти
- Регулярно очищайте логи
