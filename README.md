# 🚀 Telegram Mass Account Management Platform

Профессиональная платформа для массового управления аккаунтами Telegram (до 5000+) с полным набором инструментов для парсинга, рассылки, продвижения и аналитики.

## ✨ Полный функционал

### 📇 Управление Аккаунтами (до 5000+)
- **Автоматическая регистрация** с виртуальными номерами (SMS-Activate, 5SIM, SMS-Man)
- **Массовая загрузка** готовых сессий (.session файлов)
- **Автоматическое извлечение** API ключей из сессий
- **Панель управления** - установка аватаров, имен, описаний в несколько кликов
- **Система прокси** с поддержкой файлов и API (good proxy)
- **Гео-привязка** прокси по странам
- **Массовая проверка** аккаунтов (ТП)
- **Клонирование сессий** для защиты от недобросовестных продавцов
- **Статусы аккаунтов**: 🟢 Онлайн, 🔴 Забанен, 🟡 Проверка, ⚫ Офлайн

### 🔍 Парсинг и Сбор Аудитории
- **Парсинг каналов** и групп
- **Парсинг по геолокации**
- **Сбор участников** с фильтрацией по критериям (страна, пол, активность)
- **Анализ аудитории** - определение пола и других характеристик
- Автоматическое сохранение в базы данных
- Система задач с мониторингом прогресса
- Экспорт результатов

### ✉️ Продвижение и Рассылка
- **Массовые рассылки** по юзернеймам, ID или номерам телефонов
- **Массовые приглашения** в ваши чаты и каналы
- **Массовые подписки** на целевые каналы
- **Накрутка подписчиков** на ваши каналы
- Визуальный конструктор сообщений
- Поддержка медиа файлов
- Настройка задержек и лимитов
- Детальное логирование в реальном времени
- Статистика доставки

## 🛠 Установка и Запуск

### Требования
- Python 3.8+
- Telegram API ключи (получить на https://my.telegram.org)

### Быстрый запуск

#### Windows:
```bash
start.bat
```

#### Linux/macOS:
```bash
./start.sh
```

### Ручная установка:
```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/macOS)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python app.py
```

## 🌐 Доступ к интерфейсу

После запуска платформа будет доступна по адресу: **http://localhost:5000**

## 🔧 Настройка

### 1. Подготовка аккаунтов
1. Приобретите готовые аккаунты Telegram с файлами сессий (.session)
2. Поместите файлы .session в папку `sessions/`
3. API ключи будут извлечены автоматически из файлов сессий

### 2. Настройка прокси (рекомендуется)
1. Получите API ключ от провайдера прокси (например, good proxy)
2. Или подготовьте файл с прокси в формате: `ip:port:login:password`

### 3. Запуск платформы
1. Запустите `start.bat` (Windows) или `./start.sh` (Linux/macOS)
2. Откройте http://localhost:5000
3. Загрузите аккаунты и настройте прокси

## 📋 Использование

### Загрузка аккаунтов
1. Перейдите в "📇 Аккаунты"
2. Нажмите "Массовая Загрузка"
3. Укажите путь к папке с .session файлами
4. Настройте прокси и гео-привязку
5. Запустите "Массовая Проверка (ТП)"

### Создание рассылки
1. Перейдите в "✉️ Рассылка"
2. Создайте новую кампанию
3. Выберите базу получателей
4. Введите сообщение и настройте параметры
5. Запустите рассылку

### Парсинг данных
1. Перейдите в "🔍 Парсинг"
2. Создайте задачу парсинга
3. Выберите источник (канал, чат, геолокация)
4. Настройте параметры
5. Запустите парсинг

## ⚠️ Важные рекомендации

### Обход ограничений Telegram
- **Используйте качественные резидентские прокси** (минимум 1 прокси на 5-10 аккаунтов)
- **Настройте реалистичные задержки** между сообщениями (3-10 секунд)
- **Прогревайте новые аккаунты** перед массовыми рассылками
- **Соблюдайте лимиты**: не более 50 сообщений в день для новых аккаунтов

### Безопасность
- **Используйте Blacklist** для исключения проблемных пользователей
- **Мониторьте статистику** ошибок
- **Ротируйте прокси** регулярно
- **Не превышайте лимиты** Telegram
