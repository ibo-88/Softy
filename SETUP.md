# Инструкция по настройке Telegram Mass Platform

## 🚀 Быстрый старт

### 1. Подготовка аккаунтов Telegram

**Важно**: API ключи НЕ нужны! Они извлекаются автоматически из файлов сессий.

1. Приобретите готовые аккаунты Telegram с файлами сессий (.session)
2. Поместите файлы .session в папку `sessions/`
3. Система автоматически извлечет API ключи из каждого файла сессии

### 2. Подготовка прокси

**Вариант 1: Файл с прокси**
Создайте файл `proxies.txt` в формате:
```
ip:port:username:password
192.168.1.100:8080:user1:pass1
192.168.1.101:8080:user2:pass2
```

**Вариант 2: API провайдера**
Получите API ключ от провайдера прокси (например, good proxy)

### 3. Запуск платформы

#### Windows:
```bash
start.bat
```

#### Linux/macOS:
```bash
./start.sh
```

### 4. Доступ к интерфейсу

Откройте браузер и перейдите по адресу: **http://localhost:5000**

## 📇 Настройка аккаунтов

### Подготовка сессий

1. Создайте папку `sessions` в корне проекта
2. Поместите в неё файлы `.session` от Telethon
3. Или создайте сессии через код:

```python
from telethon import TelegramClient

api_id = 12345678  # Ваш API ID
api_hash = 'your_api_hash'  # Ваш API Hash

client = TelegramClient('session_name', api_id, api_hash)
client.start()
```

### Загрузка аккаунтов в платформу

1. Откройте вкладку "📇 Аккаунты"
2. Нажмите "Массовая Загрузка"
3. Укажите путь к папке с `.session` файлами
4. Нажмите "Загрузить"

## 🌐 Настройка прокси

### Вариант 1: Файл с прокси

1. Создайте файл `proxies.txt` в формате:
```
ip:port:username:password
192.168.1.100:8080:user1:pass1
192.168.1.101:8080:user2:pass2
```

2. В интерфейсе выберите "Управление Прокси" → "Загрузка из файла"

### Вариант 2: API Good Proxy

1. Получите API ключ от провайдера прокси
2. В настройках "API Ключи" введите ключ
3. Нажмите "Тест подключения"

### Гео-привязка прокси

1. В разделе "Аккаунты" нажмите "Гео-привязка"
2. Выберите страну
3. Система автоматически назначит прокси из выбранной страны

## ✉️ Создание рассылки

### 1. Подготовка списка юзернеймов

Создайте файл с юзернеймами в формате TXT:
```txt
@username1
@username2
username3
@username4
username5
```

### 2. Создание спам-кампании

1. Перейдите в "✉️ Рассылка"
2. Заполните форму:
   - **Название кампании**: Описательное название
   - **База получателей**: Выберите "Загрузить файл"
   - **Файл с юзернеймами**: Загрузите ваш .txt файл
   - **Сообщение**: Текст сообщения (до 4096 символов)
   - **Задержки**: Настройте интервалы между сообщениями
3. Нажмите "Запустить рассылку"

### 3. Мониторинг рассылки

- Следите за логами в реальном времени
- Проверяйте статистику доставки
- Автоматически добавляются в Blacklist заблокированные пользователи

## 🔍 Парсинг данных

### Создание задачи парсинга

1. Перейдите в "🔍 Парсинг"
2. Заполните форму:
   - **Название задачи**: Описательное название
   - **Тип источника**: Канал, чат, геолокация или хештег
   - **Источник**: Ссылка или координаты
   - **Параметры**: Количество участников, радиус и т.д.
3. Нажмите "Запустить парсинг"

## 🚫 Управление Blacklist

### Автоматическое добавление

Система автоматически добавляет в Blacklist:
- Пользователей с ошибкой `USER_BANNED`
- Чаты с ошибкой `CHAT_FORBIDDEN`
- Недействительные ID (`PEER_ID_INVALID`)

### Ручное управление

1. Перейдите в "🚫 Blacklist"
2. Нажмите "Добавить вручную"
3. Заполните форму и нажмите "Добавить"

## ⚠️ Рекомендации по безопасности

### Обход ограничений Telegram

1. **Используйте качественные прокси**:
   - Резидентские прокси предпочтительнее
   - 1 прокси на 5-10 аккаунтов
   - Регулярная ротация

2. **Настройте реалистичные задержки**:
   - 3-10 секунд между сообщениями
   - 10-30 секунд между аккаунтами
   - Случайные вариации

3. **Прогревайте аккаунты**:
   - Небольшая активность в первые дни
   - Постепенное увеличение нагрузки
   - Не более 50 сообщений в день для новых аккаунтов

4. **Мониторьте статистику**:
   - Процент успешных отправок
   - Количество ошибок
   - Статусы аккаунтов

### Соблюдение правил

- Используйте только для собственных аккаунтов
- Получайте согласие на рассылки
- Соблюдайте законодательство
- Не спамьте и не нарушайте правила Telegram

## 🔧 Устранение неполадок

### Частые проблемы

1. **Ошибка "Invalid API ID"**:
   - Проверьте правильность API ID и Hash
   - Убедитесь, что приложение создано на my.telegram.org

2. **Проблемы с прокси**:
   - Проверьте работоспособность прокси
   - Убедитесь в правильности формата
   - Проверьте логин/пароль

3. **Аккаунты не подключаются**:
   - Проверьте файлы сессий
   - Убедитесь в правильности API ключей
   - Проверьте интернет-соединение

4. **Медленная работа**:
   - Уменьшите количество потоков
   - Увеличьте задержки
   - Проверьте производительность прокси

### Логи и отладка

Логи сохраняются в файл `telegram_platform.log`. Для отладки:

1. Установите уровень логирования на DEBUG
2. Проверьте логи на наличие ошибок
3. Используйте консоль браузера для отладки JavaScript
